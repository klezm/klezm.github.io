I'm a computer science student, and this is where I write things down — mostly
about type systems, programming languages, and whatever I happen to be
building.

Posts here can carry proper mathematical notation, which is most of the reason
the site exists at all. Something like

$$
\Gamma \vdash e : \tau
$$

reads considerably better than trying to describe it in prose.

The site is built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build). Comments are powered by
[Giscus](https://giscus.app), so they live in this repository's GitHub
Discussions rather than in a third-party database — you need a GitHub account
to leave one, and you can edit or delete it any time.

If you want to follow along, there's an [RSS feed](/blog/rss.xml).
