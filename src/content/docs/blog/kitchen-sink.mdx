## Citations

A post that declares a `bibliography:` in its frontmatter can cite entries by
key. Hindley–Milner type inference was introduced in [@milner1978theory] and
given its principal-types treatment in [@damas1982principal]; the unification
walkthrough follows [@krishnamurthi2007plai]. The reference list at the bottom
is generated from BibTeX.

## Asides and custom blocks

Starlight's asides use the `:::` directive syntax:

:::note
This is a note.
:::

:::tip[Custom title]
Asides take an optional title in square brackets.
:::

:::caution
Use this one sparingly.
:::

Custom block types come from `starlight-markdown-blocks`, which extends the
same syntax rather than replacing it:

:::idea
Adding a new block type is a config change, not a component.
:::

:::proof[By induction]
Custom blocks take an optional label too.
:::

## GitHub alerts

Notes copied straight out of a README render correctly:

> [!WARNING]
> Urgent info that needs immediate attention.

> [!IMPORTANT]

## Math

Inline math such as $f : A \to B$ sits in the flow of a sentence, while display
math gets its own block:

$$
\frac{\partial}{\partial t} \psi(x, t)
  = \frac{i\hbar}{2m} \frac{\partial^2}{\partial x^2} \psi(x, t)
$$

A wider one, to exercise horizontal scrolling inside the full-bleed layout:

$$
\underbrace{\left( \sum_{i=1}^{n} a_i b_i \right)^2}_{\text{inner product}}
  \leq
\underbrace{\left( \sum_{i=1}^{n} a_i^2 \right)}_{\|a\|^2}
\underbrace{\left( \sum_{i=1}^{n} b_i^2 \right)}_{\|b\|^2}
$$

## Code

Code blocks break out of the prose column and keep their own scroll:

```haskell title="Unify.hs"
data Type
  = TVar Name
  | TCon Name
  | TApp Type Type
  deriving (Eq, Show)

unify :: Type -> Type -> Either UnificationError Subst
unify (TVar v) t = bind v t
unify t (TVar v) = bind v t
unify (TCon a) (TCon b)
  | a == b = Right mempty
unify (TApp l1 r1) (TApp l2 r2) = do
  s1 <- unify l1 l2
  s2 <- unify (apply s1 r1) (apply s1 r2)
  pure (s2 <> s1)
unify t1 t2 = Left (Mismatch t1 t2)
```

anchor jumps when JavaScript is unavailable[^progressive].
